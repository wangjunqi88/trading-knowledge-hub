A responsive, beginner-friendly educational website covering crypto, forex, and gold. Created for a university assignment about reusable AI project instructions.

## Preview locally
Open `index.html` in any modern browser. No installation, server, or API key required.

## Deploy on GitHub Pages
1. Create a public GitHub repository named `trading-knowledge-hub`.
2. Upload **the contents of this folder** to the repository root, including `index.html`, `AGENTS.md`, `assets/`, and `content/`.
3. Go to **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
4. Wait for GitHub Pages to publish and visit `https://YOUR-USERNAME.github.io/trading-knowledge-hub/` (replace `YOUR-USERNAME`).
5. Copy the actual repository URL and published website URL into the assignment report before submission.

## Maintain and extend
Read [AGENTS.md](AGENTS.md) first. Add a lesson by adding one object to `content/lessons.js`. No HTML duplication is needed.
